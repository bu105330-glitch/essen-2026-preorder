# SPIEL Essen 2026 展會指南與完整遊戲清單

網站整合四個區塊：

- SPIEL Essen 歷史與經官方核實的 2026 展會資訊
- 2026 大型活動與參加方式
- 依 BGG GeekPreview thumbs 排序的展前熱門 100
- 可搜尋、篩選、收藏與匯出的完整遊戲／預購清單

遊戲資料每日合併兩個 BoardGameGeek 公開來源：

- SPIEL Essen 2026 GeekPreview #93：完整展會遊戲與攤位資料
- Essen 2026 Preorder Pickups GeekList #380039：Pickup／Pre-order 標記與連結

熱門 100 是 GeekPreview 的展前關注度指標，不等同 BGG 全站 Hotness 或品質排名。每款遊戲均提供 BGG 頁面、玩家評論與規則檔案入口；站內導讀依公開的人數、重度、類型與機制資料產生。

GitHub Actions 每天於台北時間 06:07 執行 `scripts/build_site.py`。更新程式會先核對所有分頁與來源筆數，確認資料完整後才重建 `index.html`，再由 GitHub Pages 發布。
